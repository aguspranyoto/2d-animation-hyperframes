# 2D Animation HyperFrames

A reusable Agent Skill for turning an approved voiceover and emotion-tagged narration script into a consistent 2D animated video with HyperFrames. It uses the visual references in this repository to keep the look consistent.

## What it does

- Builds the animation from `vo.mp3` and `script.txt` supplied by the user.
- Reads `[emotion]` tags from the script to drive beats, expressions, and pacing.
- Derives word-level timing from the audio (or reuses a timestamp export when one is supplied).
- Reads the images in `references/visual-style/overall/` as the project's style reference.
- Creates a short test scene, previews it, then continues to the full animation and MP4 render.

It does not draft or rewrite narration by default. The supplied voiceover and script are the source of truth. Emotion tags are delivery instructions: they are never spoken or captioned.

## Inputs

Put the current video's files in the project, preferably here:

```text
assets/audio/
├── vo.mp3
└── script.txt
```

`script.txt` contains the narration with emotion tags. A line holding only a tag such as `[excited]` or `[ curious ]` applies to the narration block that follows, until the next tag:

```text
[excited]
Adik-adik, pernah nggak sih kalian melihat jerapah?

[curious]
Wah, lehernya panjang sekali, ya!
```

Blank lines only separate blocks. If the voiceover was generated by ElevenLabs, these tags were the delivery instructions, so keep them exactly as written.

For timing, the skill prefers a word/segment timestamp export (ElevenLabs JSON) when one is provided for the same audio, and otherwise transcribes or aligns `vo.mp3` against the script text. Before animation, it checks that every block maps to a span in the audio and that the timings fit the audio duration. Fix mismatched files before continuing.

## Visual references

Add approved 2D visual reference images to:

```text
references/visual-style/overall/
```

The skill reads all images there together and derives one consistent visual guide for palette, shapes, characters, depth, typography, and motion. Keep approved references in this folder for future videos. The visual direction stays 2D.

## Use the skill

In Claude Code, invoke it with:

```text
/2d-animation-hyperframes Create a 2D animated video using vo.mp3 and script.txt. Follow the visual references in references/visual-style/overall/.
```

In Codex, install the skill into the project's `.agents/skills/2d-animation-hyperframes/` directory and invoke it with:

```text
$2d-animation-hyperframes Create a 2D animated video using vo.mp3 and script.txt. Follow the visual references in references/visual-style/overall/.
```

In Gemini CLI, install the repository as an Agent Skill, verify it with `/skills list`, then ask Gemini to make the video using `vo.mp3` and `script.txt`. Gemini activates skills from the request; `/skills` is its management command.

## Production flow

1. Find the provided MP3, `script.txt`, and reference images.
2. Validate the files and map emotion-tag blocks to scene beats.
3. Create a short 2D test scene using the established reference style and actual voiceover.
4. Preview synchronization and visual consistency, then refine.
5. Complete the animation and render the approved project to MP4.

HyperFrames CLI and its local render requirements must be available in the environment. The `npx hyperframes preview` command opens the browser-based HyperFrames Studio; the separate desktop Studio app is optional for this workflow.
