# 2D visual references

Put all approved visual reference images in `overall/`:

```text
overall/
├── scene1.jpeg
├── scene2.jpeg
└── ...
```

The skill inspects these images together and derives one consistent visual guide for the animation, including palette, character design, 2D depth, typography, and motion. Keep new references in the same art direction. Use filenames with numbers when sequence order matters.

The animation should remain 2D. Layering, parallax, overlap, scale, shadows, and gradients can suggest depth without turning the art into 3D.
